## NotebookLM-Style Content APIs and Private Notebooks 📚

**Public content-generation APIs with an optional dedicated notebook plan**

Google now documents NotebookLM Enterprise APIs for enterprise notebook workflows, while the standalone Google Cloud Podcast API is deprecated and not accepting new customers. AutoContent API provides a public REST API for teams that need NotebookLM-style audio generation and content automation:

- **Complete API Solution**: Comprehensive document analysis API that delivers intelligent note-taking capabilities
- **Purpose-Built for Developers**: Production-ready API with advanced document processing and developer-friendly integration
- **Published Operations Only**: Use the dedicated documentation to distinguish currently enabled Private Notebook operations from the existing podcast and content-generation APIs

## API Information 🔧

### Sample API Request
```bash
curl -X POST 'https://api.autocontentapi.com/Content/Create' \
  -H 'accept: text/plain' \
  -H 'Authorization: Bearer YOUR_TOKEN_HERE' \
  -H 'Content-Type: application/json' \
  -d '{
    "resources": [
      {
        "content": "https://autocontentapi.com",
        "type": "website"
      },
      {
        "content": "74% of businesses expect AI to increase productivity",
        "type": "text"
      }
    ],
    "text": "Explain why automating with AutoContent API is a game changer for any business",
    "outputType": "audio"
  }'
```

### Key Features:
- **Multiple Sources**: Process websites, plain text, YouTube videos, PDF files
- **Smart Processing**: AI analyzes content context and relationships
- **Flexible Outputs**: Generate podcasts, FAQs, study guides, timelines, briefing documents
- **Professional Documentation**: Complete API documentation available
- **Developer-Friendly**: Easy integration with comprehensive SDKs
